01

Alcance & Metodología de Scouting

Diseñado para captadores de talento, directores deportivos y agentes que monitorean prospectos dentro y fuera de la academia.

Evaluación Multidimensional
  • 4 Pilares de Observación: Técnica (control, pase, regate), Táctica (visión, posicionamiento), Fisiológica (velocidad, biotipo, resistencia) y Psicosocial (carácter, resiliencia, entorno familiar).
  • Etiquetas de Potencial: Categorización automática: `Fichaje Inmediato`, `En Seguimiento`, `Poco Proyectable`.
  • Promoción Rápida: Conversión de un prospecto scouted en jugador activo de la academia en 1 clic.
Dossier de Exportación & FIFA Solidarity
  • PDF Pro Ejecutivo: Genera un informe estéticamente impecable con gráficos radar, historial de partidos observados y enlaces QR a video clips en YouTube/Vimeo.
  • Historial Formativo: Registro de años y meses de permanencia en el club para reclamo de mecanismo de solidaridad FIFA en futuras ventas profesionales.

Contrato de APIs REST (Scouting)

Servicios de captación y exportación de fichas técnicas de alto rendimiento.

GET/api/v1/scouting/prospectos
Lista los prospectos con filtros por posición, rango de edad, pie hábil y puntuación global.
POST/api/v1/scouting/evaluaciones
Registra una nueva visoría de campo con cálculo de puntuación ponderada y observaciones.
GET/api/v1/scouting/:id/dossier-pdf
Genera el archivo PDF ejecutivo listo para presentar a clubes profesionales o intermediarios.
POST/api/v1/scouting/:id/promover-a-plantel
Convierte el prospecto en jugador activo, asignándole categoría y abriendo su expediente 360°.

Rúbrica & Matriz de Ponderación

Criterios de puntuación estandarizados.

PONDERACIÓN GLOBAL = (Técnica x 0.35) + (Táctica x 0.25) + (Física x 0.20) + (Mental x 0.20)

CALIFICACIONES:
- 9.0 a 10.0: Talento Excepcional (Fichaje Inmediato / Proyección Primera División)
- 7.5 a 8.9 : Alto Potencial (Incorporación a Plantel Competitivo A)
- 6.0 a 7.4 : En Desarrollo (Plantel Formativo B / Seguimiento de 6 meses)
- < 6.0     : No recomendado para plantilla competitiva

Componente Angular 18 con Signals

Ficha de evaluación rápida con sliders táctiles para ojeadores en cancha.

import { Component, signal, computed, inject } from '@angular/core';
import { ScoutingService } from './scouting.service';

@Component({
  selector: 'app-scouting-evaluador',
  standalone: true,
  template: `
    <div class="scouting-card">
      <h3>Visoría: {{ prospectoNombre() }}</h3>
      
      <div class="slider-row">
        <label>Técnica (35%): <strong>{{ scoreTec() }}</strong></label>
        <input type="range" min="1" max="10" step="0.5" [value]="scoreTec()" (input)="scoreTec.set(+$any($event.target).value)" />
      </div>

      <div class="slider-row">
        <label>Táctica (25%): <strong>{{ scoreTac() }}</strong></label>
        <input type="range" min="1" max="10" step="0.5" [value]="scoreTac()" (input)="scoreTac.set(+$any($event.target).value)" />
      </div>

      <div class="slider-row">
        <label>Física (20%): <strong>{{ scoreFis() }}</strong></label>
        <input type="range" min="1" max="10" step="0.5" [value]="scoreFis()" (input)="scoreFis.set(+$any($event.target).value)" />
      </div>

      <div class="slider-row">
        <label>Mental (20%): <strong>{{ scoreMen() }}</strong></label>
        <input type="range" min="1" max="10" step="0.5" [value]="scoreMen()" (input)="scoreMen.set(+$any($event.target).value)" />
      </div>

      <div class="kpi-final">
        Puntuación Ponderada: <span class="badge-gold">{{ scoreGlobal() }} / 10.0</span>
      </div>
    </div>
  `
})
export class ScoutingEvaluadorComponent {
  readonly prospectoNombre = signal('Carlos Andrés Mina (Delantero)');
  readonly scoreTec = signal(8.0);
  readonly scoreTac = signal(7.5);
  readonly scoreFis = signal(9.0);
  readonly scoreMen = signal(8.5);

  readonly scoreGlobal = computed(() => {
    const val = (this.scoreTec() * 0.35) + (this.scoreTac() * 0.25) + (this.scoreFis() * 0.20) + (this.scoreMen() * 0.20);
    return val.toFixed(1);
  });
}

Pruebas E2E Exhaustivas (Playwright)

Verificación de fidelidad matemática de la rúbrica y generación de dossiers sin errores.

Suite de Prueba: `e2e/scouting-visorias.spec.ts`
  • Strict Error Sniffer: `attachStrictErrorSniffer(page)` activo en todo el ciclo de captación.
  • Cálculo Reactivo de Rúbrica: Validar que al deslizar los sliders el score global coincida exactamente con la fórmula matemática.
  • Descarga de Dossier PDF: Verificar que la llamada al endpoint retorne un payload de tipo `application/pdf` con código 200 y tamaño > 100KB.
  • Promoción a Jugador: Comprobar que tras promover a un prospecto se cree el registro en la tabla `jugadores` y se inactive en `prospectos_scouting`.
