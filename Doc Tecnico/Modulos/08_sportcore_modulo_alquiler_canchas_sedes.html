01

Alcance & Reglas de Negocio

El módulo permite a la administración del club o complejo deportivo maximizar la ocupación de sus canchas sin solapamientos con los entrenamientos formativos.

Prioridad Formativa vs Alquiler
  • Bloqueo Automático: Los horarios de entrenamiento y partidos federados de las categorías del club se reservan de forma automática con prioridad absoluta.
  • Disponibilidad Abierta: Los espacios restantes se ofertan al público particular o empresas con reserva previa y pago de seña (mínimo 50% vía PSE).
  • Tiempos de Gracia: Liberación automática de reservas no pagadas tras 20 minutos de espera en checkout.
Tarificación Inteligente
  • Diferenciación Horaria: Tarifa estándar diurna (06:00 a 18:00) y tarifa nocturna con recargo de iluminación LED (18:00 a 23:00).
  • Recargo de Fin de Semana: Tarifa diferencial para sábados, domingos y festivos.
  • Convenios Empresariales: Planes de abonos mensuales con descuento para torneos corporativos.

03

Contrato de APIs REST (Alquileres)

Endpoints de alta concurrencia con validación de traslape horario y cobro electrónico.

GET/api/v1/canchas/disponibilidad
Retorna la grilla de slots de 60 minutos con estado (`disponible`, `bloqueado_club`, `ocupado_particular`) para una fecha y sede específicas.
POST/api/v1/canchas/reservas
Crea una reserva temporal asegurando bloqueo transaccional. Retorna URL de checkout Wompi para abono de seña.
PATCH/api/v1/canchas/reservas/:id/pago-caja
Registra el saldo pendiente en efectivo o datáfono en la recepción del complejo antes del inicio del juego.
PATCH/api/v1/canchas/reservas/:id/cancelar
Cancela el turno aplicando políticas de reembolso o penalización por cancelación tardía.

Componente Angular 18 con Signals

Controlador reactivo para gestión de turnos y liquidación en recepción.

import { Component, signal, computed, inject } from '@angular/core';
import { CanchasService } from './canchas.service';

@Component({
  selector: 'app-canchas-matriz',
  standalone: true,
  template: `
    <div class="canchas-dashboard">
      <div class="header-controls">
        <input type="date" [value]="fechaSeleccionada()" (change)="onFechaChange($event)" class="sport-input" />
        <div class="kpi-tag">Ocupación Hoy: <strong>{{ porcentajeOcupacion() }}%</strong></div>
      </div>

      <div class="matriz-grid">
        @for (cancha of canchasDisponibles(); track cancha.id) {
          <div class="cancha-col">
            <div class="cancha-hdr">{{ cancha.nombre }} ({{ cancha.tipo_superficie }})</div>
            @for (slot of cancha.slots; track slot.hora_inicio) {
              <button 
                class="slot-btn" 
                [class.disponible]="slot.estado === 'disponible'"
                [class.ocupado]="slot.estado === 'ocupado_particular'"
                [class.club]="slot.estado === 'bloqueado_club'"
                (click)="reservarSlot(cancha, slot)">
                <span class="hora">{{ slot.hora_inicio }} - {{ slot.hora_fin }}</span>
                <span class="estado">{{ slot.estado_label }}</span>
              </button>
            }
          </div>
        }
      </div>
    </div>
  `
})
export class CanchasMatrizComponent {
  private canchasService = inject(CanchasService);

  readonly fechaSeleccionada = signal(new Date().toISOString().split('T')[0]);
  readonly canchasDisponibles = signal([]);

  readonly porcentajeOcupacion = computed(() => {
    const totalSlots = this.canchasDisponibles().flatMap(c => c.slots).length;
    if (!totalSlots) return 0;
    const ocupados = this.canchasDisponibles().flatMap(c => c.slots).filter(s => s.estado !== 'disponible').length;
    return Math.round((ocupados / totalSlots) * 100);
  });

  onFechaChange(e: Event) {
    const val = (e.target as HTMLInputElement).value;
    this.fechaSeleccionada.set(val);
    this.cargarMatriz();
  }

  reservarSlot(cancha: any, slot: any) {
    if (slot.estado !== 'disponible') return;
    // Abre modal de cobro y registro de cliente
  }

  cargarMatriz() {
    this.canchasService.getMatriz(this.fechaSeleccionada()).subscribe(res => {
      this.canchasDisponibles.set(res.canchas);
    });
  }
}

Pruebas E2E Exhaustivas (Playwright)

Garantía estricta contra errores de frontend, double-booking y persistencia en PostgreSQL.

Suite de Prueba: `e2e/canchas-reservas.spec.ts`
  • Strict Error Sniffer: `attachStrictErrorSniffer(page)` activo para detectar cualquier fallo 500 o advertencia de consola.
  • Anti-Double Booking: Ejecución de 2 reservas concurrentes sobre el mismo slot horario; la segunda DEBE responder con error 409 Conflict manejado en UI.
  • Cálculo de Tarifas Nocturnas: Verificar que reservas después de las 18:00 incluyan el recargo de iluminación en el desglose monetario.
  • Direct DB Verification: Comprobación en tabla `reservas_cancha` del cambio de estado a `confirmado` con `monto_anticipo` exacto.
