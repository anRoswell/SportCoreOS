01

Alcance & Reglas de Negocio

Gestión integral de equipamiento deportivo para jugadores, staff técnico y aficionados.

Vinculación con Ficha del Jugador
  • Talla Registrada: La talla de uniforme (camisilla, pantaloneta, medias) se sincroniza con los datos antropométricos del alumno.
  • Personalización de Dorsal: Inclusión automática del apellido y número oficial asignado al registrar el pedido del Kit Titular/Alternativo.
  • Kit de Matrícula: Generación automática de orden de entrega al completarse el pago de inscripción de temporada.
Inventario & Control de Existencias
  • Variantes por Talla: Control estricto por SKU y talla (4, 6, 8, 10, 12, 14, 16, S, M, L, XL).
  • Alerta de Quiebre de Stock: Notificación automática al administrador cuando un ítem cae por debajo del umbral mínimo de seguridad.
  • Implementos de Entrenamiento: Registro y préstamo de balones FIFA Quality, conos, vallas, petos y escaleras de agilidad.

Modelo de Datos PostgreSQL (DDL)

Estructura normalizada para control de productos, variantes por talla y órdenes de despacho.

Tablas: `productos_tienda`, `variantes_producto` & `pedidos_tienda`
Campo Tipo Restricción Descripción
id UUID PRIMARY KEY Identificador único del producto.
club_id UUID NOT NULL FK Club propietario del catálogo.
codigo_sku VARCHAR(50) NOT NULL UNIQUE Ej. "KIT-TITULAR-2026", "BALON-F5-PRO".
nombre VARCHAR(120) NOT NULL Nombre comercial del producto.
categoria VARCHAR(50) NOT NULL `uniforme_oficial`, `entrenamiento`, `accesorios`, `balones`.
precio_venta NUMERIC(12,2) NOT NULL CHECK(>0) Precio unitario de venta al público/padres.
personalizable BOOLEAN DEFAULT FALSE Indica si admite estampado de dorsal y nombre.
Campo Tipo Restricción Descripción
id UUID PRIMARY KEY Identificador de la variante de talla.
producto_id UUID NOT NULL FK Producto padre.
talla VARCHAR(10) NOT NULL Ej. "8", "10", "12", "M", "L".
stock_actual INTEGER NOT NULL DEFAULT 0 CHECK(>=0) Cantidad física disponible en bodega.
stock_minimo_alerta INTEGER NOT NULL DEFAULT 5 Umbral para disparo de reabastecimiento.
03

Contrato de APIs REST (Tienda)

Servicios de catálogo, compra electrónica e inventario.

GET/api/v1/tienda/catalogo
Lista todos los productos activos con sus variantes de tallas y disponibilidad en tiempo real.
POST/api/v1/tienda/pedidos
Genera una orden de compra vinculada a un jugador o acudiente con link de pago PSE y código QR de retiro.
PATCH/api/v1/tienda/stock/ajustar
Registra entradas por proveedor o bajas por merma/daño en bodega con auditoría de usuario.
PATCH/api/v1/tienda/pedidos/:id/entregar-qr
Valida el código QR escaneado por el utilero en secretaría y descuenta definitivamente las unidades del stock.

Componente Angular 18 con Signals

Catálogo interactivo con selector de tallas reactivo y carrito de compras.

import { Component, signal, computed, inject } from '@angular/core';
import { TiendaService } from './tienda.service';

@Component({
  selector: 'app-tienda-catalogo',
  standalone: true,
  template: `
    <div class="tienda-grid">
      @for (prod of productos(); track prod.id) {
        <div class="product-card">
          <div class="badge">{{ prod.categoria }}</div>
          <h3>{{ prod.nombre }}</h3>
          <p class="precio">\${{ prod.precio_venta | number:'1.0-0' }} COP</p>

          <div class="tallas-selector">
            @for (v of prod.variantes; track v.talla) {
              <button 
                class="talla-btn" 
                [class.selected]="prod.tallaSeleccionada === v.talla"
                [disabled]="v.stock_actual <= 0"
                (click)="seleccionarTalla(prod, v.talla)">
                {{ v.talla }} ({{ v.stock_actual }})
              </button>
            }
          </div>

          <button class="btn-comprar" [disabled]="!prod.tallaSeleccionada" (click)="agregarAlCarrito(prod)">
            <i class="fa-solid fa-cart-shopping"></i> Agregar al Carrito
          </button>
        </div>
      }
    </div>
  `
})
export class TiendaCatalogoComponent {
  private tiendaService = inject(TiendaService);

  readonly productos = signal([]);
  readonly carrito = signal([]);

  readonly totalCarrito = computed(() => {
    return this.carrito().reduce((acc, item) => acc + (item.precio_venta * item.cantidad), 0);
  });

  seleccionarTalla(producto: any, talla: string) {
    producto.tallaSeleccionada = talla;
  }

  agregarAlCarrito(producto: any) {
    this.carrito.update(items => [...items, { ...producto, cantidad: 1 }]);
  }
}

Pruebas E2E Exhaustivas (Playwright)

Verificación de stock seguro, validación de QR y tolerancia cero a fallos JS.

Suite de Prueba: `e2e/tienda-stock.spec.ts`
  • Strict Error Sniffer: `attachStrictErrorSniffer(page)` activo durante todo el checkout y escaneo.
  • Bloqueo de Stock Cero: Comprobación de que no se puedan agregar al carrito tallas con `stock_actual === 0`.
  • Validación Transaccional de Despacho: Probar que al despachar con QR, el stock en PostgreSQL se reduzca en exactamente 1 unidad.
  • Prevención de Doble Despacho: Intentar escanear el mismo QR dos veces debe arrojar alerta "Pedido ya entregado previamente".
