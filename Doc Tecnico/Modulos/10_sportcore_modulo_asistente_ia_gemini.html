Alcance & Capacidades de IA Deportiva

Transformación de datos biométricos, actas de juego y telemetría en insights humanos y recomendaciones tácticas accionables.

Boletines Técnicos en 1 Clic
  • Generación Personalizada: Redacta un reporte mensual para cada padre de familia con tono pedagógico y motivacional basado en el progreso real del alumno.
  • Consistencia de Rúbricas: Sintetiza notas de técnica individual, disciplina, asistencia a entrenamientos y minutos en cancha.

  • Detección ACWR (Acute:Chronic Workload Ratio): Cruza minutos jugados en los últimos 7 días vs promedio de 28 días.
  • Bandera Roja Preventiva: Notifica al preparador físico si un juvenil está en zona de riesgo de desgarro muscular antes del partido del fin de semana.
  • Asistente de Ejercicios DT: Sugiere dinámicas tácticas de rondos o finalización según los errores recurrentes en los últimos 3 partidos.

Contrato de APIs REST (SportCore AI)

Integración server-side con el SDK oficial `@google/genai`.

POST/api/v1/ia/generar-boletin-alumno
Compila el historial del jugador del mes y devuelve un análisis cualitativo estructurado en JSON con fortalezas y aspectos a mejorar.
GET/api/v1/ia/analisis-fatiga/:jugadorId
Calcula el ratio ACWR y devuelve recomendación de minutos máximos sugeridos para la próxima fecha.
POST/api/v1/ia/chat-tactico-dt
Endpoint con streaming Server-Sent Events (SSE) para asesorar al DT sobre variantes tácticas frente a un rival.

Componente Angular 18 con Signals

Editor interactivo donde el DT revisa, edita o aprueba la redacción generada por la IA.

import { Component, signal, inject } from '@angular/core';
import { SportAiService } from './sport-ai.service';

@Component({
  selector: 'app-boletin-ia-editor',
  standalone: true,
  template: `
    <div class="ia-panel">
      <div class="ia-header">
        <h3><i class="fa-solid fa-wand-magic-sparkles"></i> Asistente Gemini AI</h3>
        <button class="btn-ia" [disabled]="generando()" (click)="generarBoletin()">
          @if (generando()) { <i class="fa-solid fa-spinner fa-spin"></i> Redactando... }
          @else { <i class="fa-solid fa-bolt"></i> Generar Feedback Automático }
        </button>
      </div>

      <textarea 
        class="feedback-editor" 
        [value]="textoGenerado()" 
        (input)="onTextoChange($event)"
        rows="8">
      </textarea>

      <div class="actions">
        <button class="btn-approve" (click)="guardarYAprobar()">
          <i class="fa-solid fa-check"></i> Aprobar e Imprimir en PDF
        </button>
      </div>
    </div>
  `
})
export class BoletinIaEditorComponent {
  private aiService = inject(SportAiService);

  readonly generando = signal(false);
  readonly textoGenerado = signal('');

  generarBoletin() {
    this.generando.set(true);
    this.aiService.generarBoletin(123).subscribe({
      next: (res) => {
        this.textoGenerado.set(res.feedback);
        this.generando.set(false);
      },
      error: () => this.generando.set(false)
    });
  }

  onTextoChange(e: Event) {
    const val = (e.target as HTMLTextAreaElement).value;
    this.textoGenerado.set(val);
  }

  guardarYAprobar() {
    // Guarda en BD y compila el boletín PDF final para el portal de padres
  }
}

Pruebas E2E Exhaustivas (Playwright)

Garantía de respuesta rápida, manejo de fallbacks ante saturación del API de Gemini y persistencia segura.

Suite de Prueba: `e2e/ia-asistente.spec.ts`
  • Strict Error Sniffer: `attachStrictErrorSniffer(page)` activo para detectar excepciones de parsing o timeouts.
  • Fallback de Resiliencia: Mock de error 429 Rate Limit de OpenAI/Gemini; la UI debe mostrar mensaje amigable sin romper la aplicación.
  • Edición del DT: Probar que el texto propuesto por la IA pueda ser modificado manualmente por el DT antes de presionar "Aprobar".
  • Auditoría de Tokens: Comprobar que en la base de datos `ia_logs_generacion` se registren los `prompt_tokens` y `completion_tokens`.
