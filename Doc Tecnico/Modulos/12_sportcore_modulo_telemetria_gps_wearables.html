01

Alcance & Métricas Cinemáticas

Diseñado para preparadores físicos de divisiones menores y planteles competitivos que buscan datos objetivos de rendimiento.

Métricas Físicas Clave
  • Distancia Total: Metros recorridos por tiempo jugado (m/min).
  • Sprint & Alta Intensidad: Distancia recorrida a velocidades superiores a 21.0 km/h y velocidad pico alcanzada.
  • Aceleraciones & Desaceleraciones: Impactos explosivos (> 3.0 m/s²) que determinan fatiga neuromuscular.
  • PlayerLoad (AU): Vector acumulado del acelerómetro triaxial para medir la carga de choque en articulaciones.
Análisis Posicional en Cancha
  • Mapa de Calor 2D: Representación térmica que delata si un extremo mantuvo amplitud o si un central perdió su posición defensiva.
  • Comparativa vs Posición Ideal: Superposición de zonas respecto al planteamiento táctico del DT.

Modelo de Datos PostgreSQL (DDL)

Estructura particionada para almacenar millones de coordenadas GPS e índices de carga resumidos.

Tablas: `sesiones_gps` & `metricas_rendimiento_gps`
Campo Tipo Restricción Descripción
id UUID PRIMARY KEY Identificador único de la sesión de telemetría.
partido_id UUID NULLABLE FK Partido asociado (o entrenamiento si es null).
fecha_sesion DATE NOT NULL Fecha del registro.
dispositivo_marca VARCHAR(50) NOT NULL DEFAULT 'GENERIC_10HZ' `Catapult`, `Polar`, `Vmaxpro`, `GPX_Raw`.
Campo Tipo Restricción Descripción
id UUID PRIMARY KEY Identificador del resumen de telemetría.
sesion_id UUID NOT NULL FK Sesión GPS vinculada.
jugador_id UUID NOT NULL FK Jugador monitoreado.
distancia_total_m NUMERIC(8,2) NOT NULL CHECK(>=0) Metros totales recorridos.
velocidad_max_kmh NUMERIC(4,2) NOT NULL CHECK(>=0) Velocidad máxima registrada (Sprint).
distancia_sprint_m NUMERIC(8,2) NOT NULL DEFAULT 0 Metros recorridos a > 21.0 km/h.
player_load_au NUMERIC(6,2) NOT NULL CHECK(>=0) Carga acumulada triaxial (PlayerLoad).
coordenadas_heatmap_json JSONB NOT NULL Matriz de densidad normalizada X/Y para pintar el heatmap.
03

Contrato de APIs REST (Telemetría GPS)

Servicios de ingesta masiva de datos y renderizado vectorial de mapas de calor.

POST/api/v1/gps/ingesta-csv
Recibe archivo exportado desde los chalecos GPS (CSV/GPX), procesa los vectores de velocidad y calcula los resúmenes por jugador.
GET/api/v1/gps/sesion/:sesionId/jugador/:jugadorId
Retorna las métricas cuantitativas (Distancia, Sprints, PlayerLoad) con percentil de rendimiento frente a la media del equipo.
GET/api/v1/gps/heatmap-svg/:sesionId/:jugadorId
Devuelve el mapa de calor renderizado en SVG sobre una cancha de fútbol estandarizada (105m x 68m).

Componente Angular 18 con Signals

Dashboard de telemetría física con selector de jugador y visualizador térmico.

import { Component, signal, inject } from '@angular/core';
import { GpsTelemetryService } from './gps-telemetry.service';

@Component({
  selector: 'app-gps-telemetria-dashboard',
  standalone: true,
  template: `
    <div class="gps-container">
      <div class="kpis-grid">
        <div class="kpi-card">
          <span class="label">Distancia Total</span>
          <strong class="val">{{ metricas().distancia_total_m | number:'1.0-0' }} m</strong>
        </div>
        <div class="kpi-card">
          <span class="label">Velocidad Pico</span>
          <strong class="val">{{ metricas().velocidad_max_kmh }} km/h</strong>
        </div>
        <div class="kpi-card">
          <span class="label">PlayerLoad</span>
          <strong class="val">{{ metricas().player_load_au }} AU</strong>
        </div>
      </div>

      <div class="pitch-container">
        <div class="pitch-lines"></div>
        <canvas #heatmapCanvas class="heatmap-overlay"></canvas>
      </div>
    </div>
  `
})
export class GpsTelemetriaDashboardComponent {
  private gpsService = inject(GpsTelemetryService);

  readonly metricas = signal({
    distancia_total_m: 8420,
    velocidad_max_kmh: 31.4,
    player_load_au: 412
  });
}
